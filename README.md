# Habit Tracker

A simple web app for tracking daily habits and staying consistent.

## Features

- Add habits
- Check off a habit for today
- See your current streak for each habit
- Delete habits

## Running it

No build step needed — just open `index.html` in a browser. Data is saved
locally in your browser via `localStorage`.

## Sharks

The background decoration is a hand-drawn SVG shark (in `index.html`), not a
photo — its tail fin rotates independently to simulate a swimming motion.
